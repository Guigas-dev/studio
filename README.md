
# DeltaWealth | Premium Portfolio Management

Plataforma de alta performance para gestão de investimentos na B3 e mercado internacional.

## 🚀 Como fazer Deploy na Vercel

1. **Repositório**: Suba o código para o seu GitHub.
2. **Novo Projeto**: Na Vercel, selecione o repositório do DeltaWealth.
3. **Variáveis de Ambiente**:
   - Adicione a chave `GEMINI_API_KEY` com o valor da sua API Key do Google (obtenha em [Google AI Studio](https://aistudio.google.com/)).
4. **Deploy**: Clique em "Deploy".

## 🛠️ Tecnologias
- **Next.js 15** (App Router)
- **Genkit** (Processamento de dados com IA)
- **ShadCN UI** & **Tailwind CSS** (Interface Premium)
- **Recharts** (Gráficos e Benchmarks)

## 📁 Estrutura
- `/dashboard`: Visão geral e importação inteligente.
- `/portfolio`: Detalhamento de ativos e preço médio.
- `/transactions`: Histórico de compras e vendas.
- `/dividends`: Acompanhamento de renda passiva.
- `/benchmarks`: Comparação de rentabilidade contra o CDI.
