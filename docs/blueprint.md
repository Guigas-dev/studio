# **App Name**: DeltaWealth

## Core Features:

- Secure User Authentication: Allow users to register, log in (including Google SSO), and manage their accounts securely, with distinct user roles (common and admin).
- Personalized Investment Dashboard: Display a real-time overview of total portfolio value, profitability, and dividend income, along with a summary of owned assets.
- Manual Asset & Transaction Management: Enable users to manually add and categorize various investment assets (stocks, FIIs, cryptos, etc.) and record detailed buy/sell transactions, bonifications, and splits across multiple portfolios.
- Comprehensive Financial Metrics Calculation: Perform precise server-side calculations for portfolio performance metrics like average price, profit/loss, total return, dividend yield, and asset allocation percentages.
- Dividend Tracking and Projection: Monitor historical dividend payments and provide projections for future dividend income based on owned assets, presented in an elegant calendar and historical view.
- Interactive Portfolio Visualizations: Present portfolio data through modern, interactive charts (e.g., equity evolution, dividend distribution, and asset class allocation) with smooth animations and transitions.
- AI-Powered Portfolio Assistant: A tool to provide high-level, textual insights and recommendations for portfolio rebalancing or risk management based on aggregated portfolio data and user-defined goals.

## Style Guidelines:

- Primary color: Vibrant purple (#8633E6) for a modern, sophisticated, and technological focal point in a dark theme, chosen for its strong contrast and premium feel.
- Background color: A very dark, desaturated indigo (#1F1824) to establish a deep, elegant, and comfortable foundation for the dark mode UI, subtly echoing the primary hue.
- Accent color: Bright azure blue (#0D9FFA) to highlight interactive elements, calls to action, and key information, providing dynamic contrast and a tech-savvy appeal.
- Headlines: 'Space Grotesk' (sans-serif) for a modern, tech-inspired, and impactful aesthetic, reflecting a computerized and scientific feel.
- Body text: 'Inter' (sans-serif) for optimal legibility across various screen sizes and a clean, objective presentation of financial data and insights.
- Utilize clean, minimalist line icons, consistent in style and stroke weight, for clear navigation and data representation, reflecting a modern, premium FinTech aesthetic compatible with Shadcn/UI.
- Employ a modular, card-based layout with generous spacing and a responsive grid system, prioritizing information hierarchy and elegance for both desktop and mobile-first views, optimized for a sophisticated dark mode.
- Incorporate subtle, fluid animations for data visualization transitions, state changes (e.g., loading, hover), and micro-interactions, enhancing the premium user experience without distraction. Utilize elegant skeleton loading for perceived performance.
